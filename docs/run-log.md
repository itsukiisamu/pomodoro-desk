# Pomodoro Desk Run Log

## 2026-08-28

### 目的

動画埋め込みまわりを拡張し、休憩時の動画停止を検証できる状態でGitHubに反映する。

### 実装したこと

- `休憩に入ったら動画を停止` 設定を追加
- 集中完了で短い休憩 / 長い休憩に入る時、設定ONなら埋め込みプレイヤーを停止
- 集中を `SKIP` して休憩に入る時も、設定ONなら埋め込みプレイヤーを停止
- 停止時にiframeを `about:blank` に差し替えてから破棄するように変更
- YouTubeの `list=WL` は再生リスト扱いせず、単体動画として扱う
- YouTube再生リストURL、または `list=PL...` 付きURLは連続再生として扱う
- ニコニコ動画URLの基本的な埋め込み対応を追加
- Twitchチャンネル / アーカイブ / クリップURLの基本的な埋め込み対応を追加
- SoundCloudトラック / プレイリストURLの基本的な埋め込み対応を追加
- 汎用の `別タブで開く` 導線を追加
- README、product notes、検証リストを更新

### 確認したこと

- JavaScript構文チェック: OK
- URL変換テスト: OK
  - YouTube `list=WL`
  - YouTube再生リストURL
  - ニコニコ動画URL
  - TwitchチャンネルURL
  - TwitchアーカイブURL
  - SoundCloud URL
- ローカル確認用の `C:\Users\PC_User\Desktop\index.html` に反映済み

### 未解決・追加検証が必要なこと

- 実際の動画再生中に、集中完了で短い休憩へ入った時に確実に停止するか
- 実際の動画再生中に、集中を `SKIP` して休憩へ入った時に確実に停止するか
- YouTubeライブ配信で停止できるか
- YouTube再生リストで停止できるか
- Twitchは `file://` ローカル直開きでは安定検証しづらいため、GitHub Pages版で確認する
- SoundCloudは投稿者側の埋め込み設定に依存するため、複数URLで確認する

### 判断メモ

- アプリ内プレイヤーはiframeを破棄する方式なので、基本的には停止できる想定
- 別タブで開いた各サービスの再生は制御しない
- YouTube Shortsのレコメンド順やおすすめフィードは制御対象にしない
- 今後の本命は、動画stock 20件と、アプリ側で管理する作業用キュー

## 2026-08-28 動画stock追加

### 目的

再生した動画や配信URLをあとから呼び出せるようにし、YouTubeべったりの作業導線を強くする。

### 実装したこと

- BGMタイトル欄の下に `動画stock` を追加
- プレイヤー表示した動画URLを自動でstockに保存
- `今の動画をstock` ボタンで手動保存
- stock上限を20件に制限
- stockにタイトル、URL、使用回数、最終使用日時を保存
- stockから動画URLとBGMタイトルを呼び出せるようにした
- stockタイトルを後から編集できるようにした
- stockを削除できるようにした
- JSON書き出し/読み込みにstockを含めるようにした

### 追加検証が必要なこと

- 20件を超えた時に古いstockが落ちること
- BGMタイトル未入力の時に仮タイトルで保存されること
- タイトル編集後にログや成果PNGの入力値として使えること
- スマホ幅でstock操作ボタンが詰まらないこと
