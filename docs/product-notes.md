# Pomodoro Desk Product Notes

## コンセプト

推し曲・歌枠・作業用BGMと一緒に使う、作業ログつきポモドーロデスク。

## キャッチコピー案

やる気スイッチ、ココから作れます。

## 想定ユーザー

- YouTube Musicで作業BGMを流す人
- Vtuber歌枠、作業用BGM、推し曲を聞きながら作業する人
- アイマス公式楽曲やライブセトリを流しながら作業時間を区切りたい人
- 作業ログを画像で残したい人
- 普通のポモドーロタイマーが少し無機質に感じる人
- 推し活、創作、勉強、同人作業などの稼働を可視化したい人
- 夜型で、日付をまたぐ作業ログを自然に扱いたい人

## 現在の要件

- ブラウザだけで動く
- 単一HTMLで配布できる
- 集中、短い休憩、長い休憩を管理できる
- 集中時間、休憩時間、長い休憩までのセット数を変更できる
- 夜型向けに日付変更線を設定できる
- YouTube / YouTube Music / ニコニコ動画 / Twitch / SoundCloud のURLを扱える
- YouTube再生リストURL、または `list=PL...` 付きURLを連続再生できる
- YouTubeライブ配信URLを、埋め込み可能な通常動画URLとして扱える
- Twitchチャンネル、Twitchアーカイブ、SoundCloudトラック/プレイリストを埋め込み可能な範囲で扱える
- 埋め込み再生できるURLはアプリ内で表示できる
- 埋め込みできない場合は別タブで開ける
- 埋め込みプレイヤーを停止できる
- 作業ログをブラウザに保存できる
- BGMタイトルを手入力できる
- CSV / JSONでログを書き出せる
- JSONを読み込める
- 今日の作業ログを正方形PNGとして書き出せる
- 小窓表示できる
- ダーク、ライト、PC設定追従、柔らかいトマト色に切り替えられる
- 日本語 / 英語を切り替えられる

## 否要件・制約

- Googleログインや自動同期はしない
- サーバー保存はしない
- YouTube / YouTube Musicのタイトル自動取得はしない
- YouTubeやニコニコ動画の埋め込み制限は回避しない
- TwitchやSoundCloudの埋め込み制限は回避しない
- 別タブで開いた動画の再生・停止は制御しない
- YouTube Shortsのレコメンド順は取得・制御しない
- YouTubeの「後で見る」リスト（`list=WL`）を、公式再生リストとして連続再生しようとはしない
- YouTube側の推薦、広告、年齢制限、ログイン制限、公開範囲、ライブ配信の状態は制御しない
- 単純なiframe埋め込みのままでは、動画終了イベントや「次へ」操作は取得しない
- 著作権のある音源や動画をアプリ側で保存しない
- 読み取り可能なQRコード生成は現時点ではしない
- 複雑な分析ダッシュボードは作らない
- 最初から多機能な管理画面にはしない

### 実装できない・回避しない（技術的/仕様的制約）

- 別タブで開いたYouTube / YouTube Music / ニコニコ動画 / Twitch / SoundCloudの再生停止
- YouTube Shortsのおすすめ順、レコメンド順の取得
- YouTube Shortsのおすすめフィードをアプリ側で連続再生・スキップ
- YouTubeの「後で見る」リスト（`list=WL`）を公式再生リストとして安定連続再生
- YouTubeや各サービス側の広告、推薦、公開範囲、ライブ状態の制御
- 埋め込み不可、ログイン必須、年齢制限、メンバー限定、非公開、削除済み動画の再生
- YouTube / YouTube Musicのタイトル自動取得（APIキーやサーバーなしの方針では行わない）
- 著作権のある音源や動画のアプリ側保存
- Twitchの埋め込みをローカル `file://` で安定検証
- SoundCloudで投稿者が埋め込み不可にしている音源の再生

### 現在の単純iframe方式でできること

- YouTubeの通常動画URLを埋め込み表示する
- YouTubeライブ配信URLを埋め込み表示する
- YouTube再生リストURLを埋め込み表示する
- YouTube Shorts単体URLを通常動画として埋め込み表示する
- ニコニコ動画の一部URLを埋め込み表示する
- アプリ内プレイヤーを破棄して再生を停止する
- 埋め込みできない場合に別タブで開く導線を用意する

### 現在の単純iframe方式ではできないこと

- 別タブで開いたYouTube / YouTube Music / ニコニコ動画を停止する
- YouTube Shortsのおすすめ順、レコメンド順を取得する
- YouTube Shortsのおすすめフィードをアプリ側で連続再生・スキップする
- YouTubeの「後で見る」リスト（`list=WL`）を再生リストとして安定して埋め込む
- 埋め込み不可、ログイン必須、年齢制限、メンバー限定、非公開、削除済みの動画を再生する
- YouTube Musicのプレイリストを通常のYouTube再生リストと同じように安定して埋め込む
- Twitchの埋め込みをローカル `file://` で安定検証する
- SoundCloudで投稿者が埋め込み不可にしている音源を再生する
- 動画が最後まで再生されたことを検知して、自動で次の動画へ進める

### 将来的にYouTube IFrame APIを使うとできそうなこと

- アプリ側で用意した動画リストを順番に再生する
- 再生、停止、一時停止、次へ、前へをJavaScriptから制御する
- 動画終了イベントを受け取り、次のstock動画へ進める
- アプリ内再生リストのループ制御を行う

ただし、YouTube側のレコメンド順やShortsフィードそのものを取得・制御するものではない。アプリ側で保存したstockやキューを再生する方向で考える。

## 今後の拡張候補

### 動画stock

- 最近使った動画を20件まで保存
- タイトル、URL、使用回数、最終使用日時を保存
- クリックでURLとBGMタイトルを復元
- 削除できる
- `list=WL` 付きのURLは、再生リストではなく単体動画として扱う
- ライブ配信URL、通常動画、Shorts単体URL、ニコニコ動画URLを保存候補にする
- Twitchチャンネル、Twitchアーカイブ、SoundCloudトラック/プレイリストURLを保存候補にする

### 休憩時の動画停止

- 集中完了後、休憩に入るタイミングで動画を停止する
- スキップで休憩に入った場合も停止する
- 休憩中もBGMを流したい人向けに、設定でOFFにできる

### ニコニコ動画対応

- `https://www.nicovideo.jp/watch/sm...` 形式のURLを埋め込み表示できるようにする
- 埋め込みできない動画は別タブ表示へ逃がす
- ログイン必須、年齢制限、チャンネル限定、削除済み、非公開などは回避しない

### やる気スイッチ

やる気スイッチ = 行動名 + 曲URL + タイマーパターン

- 現在の設定をスイッチとして保存
- 保存したスイッチを呼び出す
- 将来的には動画stockやタイマーパターンと組み合わせる
- まずは「現在の入力欄と設定を丸ごと保存して呼び出す」程度から始める

### アプリ内再生リスト

- stockした動画を並べる
- 休憩に入ったら停止する
- 動画終了で次へ進める場合はYouTube IFrame APIを検討する
- 公式のYouTube再生リストを無理に制御しようとせず、アプリ側のstockを使う
- Shortsのレコメンド順ではなく、自分で選んだShorts URLをstockして並べる

## 開発方針

- まずは小さく入れて試す
- 使いながら違和感を直す
- UIは設定画面化しすぎない
- 推し活、創作、勉強、夜型作業に寄せる
- AI併用プロトタイピングとして進める
- 公開できる状態を保ちながら、次の機能はローカルで検証してから反映する
